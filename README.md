### ⚡ Cajoa

**A different way to build reactive interfaces.**

A beginner-friendly frontend framework exploring signals and JSX without the traditional virtual DOM approach.

- ⚡ Fine-grained reactive updates
- 🧩 JSX-based component authoring
- 🧠 Components execute once, with reactive dependencies driving updates
- 🛠️ Built to explore framework design from the ground up

`TypeScript` `JSX` `Signals`
